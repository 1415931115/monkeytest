# MONKEYBRO / 偷桃前夜

First-person orchard scavenge-and-extract. You play 猴儿 in a night pan-tao orchard: gather peaches, avoid the three fairies, and reach the extract shrine.

第一人称桃园搜寻撤离。你扮演猴儿，在夜间蟠桃园里捡桃、躲开三位仙子，抵达撤离点。

## Run / 运行

```bash
npm install
npm run dev
```

Vite serves the game on `127.0.0.1` (see `package.json`).

```bash
npm run build
npm run preview
```

## Callout / 点名

青鸾（Caller）的点名必须是 **「猴哥——」**。不要写成 monkeybro。回头即死。

The Caller line must be exactly **「猴哥——」**. Looking back is death.
